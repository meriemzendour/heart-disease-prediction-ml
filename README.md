Heart Disease Prediction Using Machine Learning

## Overview

This project uses Machine Learning algorithms to predict the presence of heart disease based on clinical data.

It includes data analysis, preprocessing, feature engineering, model training, evaluation, and a web application developed with Flask.

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Imbalanced-learn
- Matplotlib and Seaborn
- Flask
- HTML and CSS
- Jupyter Notebook

## Project Objectives

- Analyze clinical data.
- Prepare data for Machine Learning.
- Train and compare classification models.
- Evaluate model performance using different metrics.
- Provide a web interface for predictions.

## Machine Learning Models

The project explores the following classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gradient Boosting

## Installation

Clone the repository:

```bash
git clone https://github.com/meriemzendour/heart-disease-prediction-ml.git
cd heart-disease-prediction-ml
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Web Application

Open a terminal in the project directory and run:

```bash
cd app
python app.py
```

Open your browser at:

http://127.0.0.1:5000

Make sure the required model files are available in the expected location.
